# Database Schema

This directory contains the PostgreSQL schema for the **School Bus Transportation Management System**.

## Structure

| File               | Description          |
| ------------------ | -------------------- |
| 01-enums.sql       | ENUM types           |
| 02-user.sql        | User table           |
| 03-admin.sql       | Admin table          |
| 04-parent.sql      | Parent table         |
| 05-driver.sql      | Driver table         |
| 06-student.sql     | Student table        |
| 07-bus.sql         | Bus table            |
| 08-bus_stop.sql    | Bus Stop table       |
| 09-route.sql       | Route table          |
| 10-route_stop.sql  | Route Stop table     |
| 11-trip.sql        | Trip table           |
| 12-complaint.sql   | Complaint table      |
| 13-constraints.sql | Constraints          |
| 14-indexes.sql     | Indexes              |
| 99-init.sql        | Master schema script |
